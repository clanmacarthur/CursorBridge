# Session Source Library Spec

Last updated: 2026-02-21
Status: starter draft

## Purpose

Define where session content comes from and how it should be used in generation.

## Source Groups

## Group 1: Session structure

- `session_blueprints`
- `blueprint_steps`
- `blueprint_cues`
- `timing_presets`
- `session_phases`
- `transition_rules`

## Group 2: Technique content

- `techniques`
- `technique_steps`
- `technique_lens_explanations`

## Group 3: Theme and meaning content

- See `docs/THEME_TABLE_CATALOG.md` for planned domain mapping.

## Group 4: Voice and explanation

- `narration_styles`
- `lens_definitions`
- `meta_lens_presets`
- `archetypal_personas`
- `knowledge_bases`

## Build Rule

Session timeline timing must come from structure tables.
Lens and persona change wording, not phase timing math.
