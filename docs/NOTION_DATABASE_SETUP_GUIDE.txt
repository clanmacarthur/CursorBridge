================================================================================
CURSORBRIDGE - NOTION DATABASE SETUP GUIDE
================================================================================

Create 8 automation databases in Notion with ONE COMMAND.

================================================================================
QUICK START (THE EASY WAY)
================================================================================

Prerequisites:
1. NOTION_TOKEN set in your .env file
2. A Notion page where you want the databases created

Then just run:

    python scripts/create_notion_databases.py --page YOUR_NOTION_LINK

Example:

    python scripts/create_notion_databases.py --page https://www.notion.so/My-Wellness-App-2d9c47c61e2180a1848bd93728f116cd

That's it! The script will:
- Extract the page ID from your link
- Create all 8 databases with proper columns
- Set up all relations between databases
- Save the database IDs for future syncing


================================================================================
WHAT GETS CREATED
================================================================================

| Database                    | Columns | Purpose                              |
|-----------------------------|---------|--------------------------------------|
| Control Definitions (DB)    | 17      | Every knob/tick the UI can render    |
| Control Packs (DB)          | 12      | Curated bundles of controls          |
| Profile Pack Map (DB)       | 6       | Links profiles to default packs      |
| Default Weights (DB)        | 7       | Baseline weights per profile         |
| Coupling Rules (DB)         | 17      | How controls influence each other    |
| Derived Metrics (DB)        | 14      | Computed scores from raw values      |
| Questionnaires (DB)         | 8       | Questionnaire definitions            |
| Questionnaire Questions (DB)| 10      | Questions within questionnaires      |


================================================================================
COMMAND OPTIONS
================================================================================

Preview what will be created (doesn't actually create anything):

    python scripts/create_notion_databases.py --page YOUR_LINK --dry-run

Create the databases:

    python scripts/create_notion_databases.py --page YOUR_LINK

The --page argument accepts:
- Full Notion URL: https://www.notion.so/Page-Name-2d9c47c61e2180a1848bd93728f116cd
- Just the page ID: 2d9c47c61e2180a1848bd93728f116cd
- ID with dashes: 2d9c47c6-1e21-80a1-848b-d93728f116cd


================================================================================
AFTER CREATION
================================================================================

1. Go to your Notion page - you'll see all 8 databases
2. Add entries directly in Notion's visual interface
3. Sync to Supabase when ready using CursorBridge

Database IDs are saved to: config/notion_db_ids.json


================================================================================
MANUAL SETUP (IF YOU PREFER)
================================================================================

If you want to create databases manually instead of using the script,
see the detailed column specifications below:

--------------------------------------------------------------------------------
DATABASE 1: CONTROL DEFINITIONS
--------------------------------------------------------------------------------
Purpose: Every knob/tick/slider the UI can render

Columns:
- Control Name (Title)
- Control Type (Select): slider, checkbox, knob, hybrid, number, text, time
- Primary Domain (Relation -> Attribute Taxonomy, Limit 1)
- Secondary Domains (Relation -> Attribute Taxonomy, No limit)
- Range Min (Number)
- Range Max (Number)
- Range Step (Number)
- Default Value (Number)
- Unit (Text): hours, ml, score, minutes, etc.
- Label (Text)
- Description (Text)
- Icon (Text)
- Is Required (Checkbox)
- Is Default (Checkbox)
- Completion Threshold (Number)
- Status (Select): Active, Deprecated, Archived
- Notes (Text)

--------------------------------------------------------------------------------
DATABASE 2: CONTROL PACKS
--------------------------------------------------------------------------------
Purpose: Curated bundles of controls for drag/drop

Columns:
- Pack Name (Title)
- Pack Slug (Text): URL-safe identifier
- Description (Text)
- Category (Select): Wellness, Fitness, Nutrition, Sleep, Stress, Custom
- Difficulty (Select): Beginner, Intermediate, Advanced
- Controls (Relation -> Control Definitions, No limit)
- Icon (Text)
- Display Order (Number)
- Is Public (Checkbox)
- Is Default (Checkbox)
- Status (Select): Active, Deprecated, Archived
- Notes (Text)

--------------------------------------------------------------------------------
DATABASE 3: PROFILE PACK MAP
--------------------------------------------------------------------------------
Purpose: Links Programme Profiles to their default Control Packs

Columns:
- Mapping Name (Title)
- Programme Profile (Relation -> Programme Profiles, Limit 1)
- Control Pack (Relation -> Control Packs, Limit 1)
- Display Order (Number)
- Is Required (Checkbox)
- Notes (Text)

--------------------------------------------------------------------------------
DATABASE 4: DEFAULT WEIGHTS
--------------------------------------------------------------------------------
Purpose: Baseline importance weights per programme profile

Columns:
- Weight Name (Title)
- Programme Profile (Relation -> Programme Profiles, Limit 1)
- Attribute (Relation -> Attribute Taxonomy, Limit 1)
- Weight (Number): 0.0 to 1.0
- Weight Label (Select): High, Medium, Low, None
- Domain (Select): Recovery, Nutrition, Movement, Sleep, Stress, Cognitive, Spiritual
- Notes (Text)

--------------------------------------------------------------------------------
DATABASE 5: COUPLING RULES
--------------------------------------------------------------------------------
Purpose: THE ADAPTIVE ENGINE - How controls influence each other

Columns:
- Rule Name (Title)
- From Control (Relation -> Control Definitions, Limit 1)
- From Attribute (Relation -> Attribute Taxonomy, Limit 1)
- From Metric (Text)
- To Control (Relation -> Control Definitions, Limit 1)
- To Attribute (Relation -> Attribute Taxonomy, Limit 1)
- To Metric (Text)
- Function Type (Select): Linear, Threshold, Conditional, Decay, Inverse, Step
- Direction (Select): Positive, Negative, Conditional
- Magnitude (Number): 0.0 to 2.0
- Threshold Value (Number)
- Threshold Comparator (Select): >=, <=, =, Between, Above, Below
- Applies To Profiles (Relation -> Programme Profiles, No limit)
- Priority (Number)
- Evidence Confidence (Select): Strong, Moderate, Emerging, Traditional
- Status (Select): Active, Deprecated, Archived
- Notes (Text)

--------------------------------------------------------------------------------
DATABASE 6: DERIVED METRICS
--------------------------------------------------------------------------------
Purpose: Computed scores from raw check-in values

Columns:
- Metric Name (Title)
- Metric Slug (Text)
- Description (Text)
- Formula Type (Select): Weighted Average, Sum, Min, Max, Custom
- Input Controls (Relation -> Control Definitions, No limit)
- Output Min (Number)
- Output Max (Number)
- Unit (Text)
- Threshold Low (Number)
- Threshold Medium (Number)
- Threshold High (Number)
- Domain (Select): Recovery, Sleep Quality, Nutrition Quality, Stress Load, Energy, Focus, Mood
- Status (Select): Active, Deprecated, Archived
- Notes (Text)

--------------------------------------------------------------------------------
DATABASE 7: QUESTIONNAIRES
--------------------------------------------------------------------------------
Purpose: Questionnaire definitions for profile assignment

Columns:
- Questionnaire Name (Title)
- Questionnaire Slug (Text)
- Description (Text)
- Version (Number)
- Is Active (Checkbox)
- Is Onboarding (Checkbox)
- Scoring Method (Select): Weighted, Simple, Branching
- Notes (Text)

--------------------------------------------------------------------------------
DATABASE 8: QUESTIONNAIRE QUESTIONS
--------------------------------------------------------------------------------
Purpose: Individual questions within questionnaires

Columns:
- Question Text (Title)
- Questionnaire (Relation -> Questionnaires, Limit 1)
- Question Type (Select): Single Choice, Multi Choice, Scale, Text, Yes/No
- Options (Text)
- Scale Min (Number)
- Scale Max (Number)
- Weight (Number)
- Display Order (Number)
- Is Required (Checkbox)
- Notes (Text)
